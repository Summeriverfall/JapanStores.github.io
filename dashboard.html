⚙️ Google Apps Script 设置说明

如何设置 Google Apps Script 以实现网页直接更改月份：

  1. 在 Google Sheets 中，点击 扩展程序 → Apps Script
  2. 复制以下代码并粘贴到编辑器：
    3. function doGet(e) {
  const sheetId = e.parameter.sheetId;
  const month = e.parameter.month;
  const action = e.parameter.action;
  
  if (action === 'updateMonth') {
    try {
      const ss = SpreadsheetApp.openById(sheetId);
      const dashboardSheet = ss.getSheetByName('Dashboard');
      
      if (!dashboardSheet) {
        return ContentService.createTextOutput(JSON.stringify({
          success: false,
          error: '找不到 Dashboard sheet'
        })).setMimeType(ContentService.MimeType.JSON);
      }
      
      // 更新 B2 单元格为选择的月份
      dashboardSheet.getRange('B2').setValue(month);
      
      return ContentService.createTextOutput(JSON.stringify({
        success: true,
        message: '月份已更新'
      })).setMimeType(ContentService.MimeType.JSON);
    } catch (error) {
      return ContentService.createTextOutput(JSON.stringify({
        success: false,
        error: error.toString()
      })).setMimeType(ContentService.MimeType.JSON);
    }
  }

  if (action === 'updateDay') {
    try {
      const ss = SpreadsheetApp.openById(sheetId);

          error: '找不到 Dashboard sheet'

      dashboardSheet.getRange('E2').setValue(e.parameter.date);
      return ContentService.createTextOutput(JSON.stringify({
        success: true,
        message: '统计日期已更新'
      })).setMimeType(ContentService.MimeType.JSON);

      return ContentService.createTextOutput(JSON.stringify({
        success: false,
        error: error.toString()
      })).setMimeType(ContentService.MimeType.JSON);
    }
  }
  
  return ContentService.createTextOutput(JSON.stringify({
    success: false,
    error: '未知操作'
  })).setMimeType(ContentService.MimeType.JSON);

  3. 点击 部署 → 新建部署
  4. 选择类型为 网页应用
  5. 执行身份选择 我，访问权限选择 任何人

⚠️ 重要：如果您的 Apps Script 中已有代码

如果您的 Apps Script 中已经有其他代码，请按照以下方式集成：

  1. 检查是否已有 doGet 函数：如果已有，需要修改现有函数来支持新的 action
  2. 如果没有 doGet 函数：直接添加提供的代码
  3. 如果有 doGet 函数：在现有函数中添加对 updateMonth、updateDay action 的处理

详见下方"集成到现有代码"部分

💡 设置完成后，您可以在网页上选择月份（更新 B2）或选择日期（更新 E2），系统会自动刷新对应统计数据。

📝 如何集成到现有代码

情况1：没有 doGet 函数（您的情况）

直接将以下代码添加到您的 Apps Script 文件末尾：

// ===== 仪表盘月份更新功能 =====
// 将此函数添加到您现有代码的末尾
function doGet(e) {
  const sheetId = e.parameter.sheetId;
  const month = e.parameter.month;
  const action = e.parameter.action;
  
  if (action === 'updateMonth') {
    try {
      const ss = SpreadsheetApp.openById(sheetId);
      const dashboardSheet = ss.getSheetByName('Dashboard');
      
      if (!dashboardSheet) {
        return ContentService.createTextOutput(JSON.stringify({
          success: false,
          error: '找不到 Dashboard sheet'
        })).setMimeType(ContentService.MimeType.JSON);
      }
      
      // 更新 B2 单元格为选择的月份
      // month 格式：YYYY-MM-DD（该月第一天）
      dashboardSheet.getRange('B2').setValue(month);
      
      return ContentService.createTextOutput(JSON.stringify({
        success: true,
        message: '月份已更新'
      })).setMimeType(ContentService.MimeType.JSON);
    } catch (error) {
      return ContentService.createTextOutput(JSON.stringify({
        success: false,
        error: error.toString()
      })).setMimeType(ContentService.MimeType.JSON);
    }
  }
  
  return ContentService.createTextOutput(JSON.stringify({
    success: false,
    error: '未知操作'
  })).setMimeType(ContentService.MimeType.JSON);
}
// ===== 仪表盘月份更新功能结束 =====

✅ 您的代码结构：您的代码主要用于同步 Google Calendar 数据，没有 doGet 函数。
✅ 添加方式：直接将上面的 doGet 函数复制到您现有代码的最后即可。
✅ 不会冲突：这个函数是独立的，不会影响您现有的 syncAllStoresDaily、syncAllStoresDeep 等函数。

情况2：已有 doGet 函数

在您现有的 doGet 函数中添加以下代码：

function doGet(e) {
  // ... 您现有的代码 ...
  
  const action = e.parameter.action;
  
  // 添加月份更新功能
  if (action === 'updateMonth') {
    try {
      const sheetId = e.parameter.sheetId;
      const month = e.parameter.month;
      const ss = SpreadsheetApp.openById(sheetId);
      const dashboardSheet = ss.getSheetByName('Dashboard');
      
      if (!dashboardSheet) {
        return ContentService.createTextOutput(JSON.stringify({
          success: false,
          error: '找不到 Dashboard sheet'
        })).setMimeType(ContentService.MimeType.JSON);
      }
      
      dashboardSheet.getRange('B2').setValue(month);
      
      return ContentService.createTextOutput(JSON.stringify({
        success: true,
        message: '月份已更新'
      })).setMimeType(ContentService.MimeType.JSON);
    } catch (error) {
      return ContentService.createTextOutput(JSON.stringify({
        success: false,
        error: error.toString()
      })).setMimeType(ContentService.MimeType.JSON);
    }
  }
  
  // ... 您现有的其他代码 ...
}

💡 提示

  • 这个新功能不会影响您现有的代码
  • 只有当 action 参数为 'updateMonth' 时才会执行月份更新功能
  • 如果您的 doGet 函数已经有其他逻辑，只需要添加 if (action === 'updateMonth') 这个判断即可
  • 添加代码后，记得重新部署 Web 应用
